# operations-ui

Aplicacion Next.js orientada a monitoreo operativo por local.

## Objetivo
Concentrar visibilidad de operaciones, alertas y estado de pedidos.

## Alcance actual
- Vista de entrada con KPIs operativos.
- Bloque de prioridades del dia para equipo de operaciones.

## Scripts
- `npm run dev`
- `npm run build`
- `npm run lint`
