# backoffice

Aplicacion interna de Brasaland para operaciones y compras.

## Objetivo
Proveer una vista inicial de dashboard e integrar desde el primer dia la logica TypeScript del Hito 2 sin duplicar codigo.

## Alcance actual
- Ruta `/` con layout interno separado de website.
- KPIs y tablas renderizados desde funciones importadas de `src/utils`.
- Alertas de stock y estado de validaciones visibles en interfaz.

## Scripts
- `npm run dev`
- `npm run build`
- `npm run lint`
