# TrackFlow Backoffice

Lightweight backoffice UI for the TrackFlow Supplier Directory.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## API integration

- Development requests use the Vite proxy at `/api` and forward to `http://127.0.0.1:8000`.
- Override the API base URL with `VITE_API_URL` when needed.
