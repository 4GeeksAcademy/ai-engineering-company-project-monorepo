Customer safety

Allergen information

Brasaland discloses allergens according to INVIMA in Colombia and the FDA in the United States. Floor staff must be able to answer allergen questions without hesitation.

If you report an allergy

  1. The server informs the kitchen before preparation begins.
  2. The kitchen uses clean utensils and a surface separate from the general prep area.
  3. “Zero cross-contamination risk” is never guaranteed — the server must say this explicitly if you have a severe allergy.

There is no certified gluten-free version of the BBQ Ribs because of the imported sauce. Ask a server about that dish every time.
