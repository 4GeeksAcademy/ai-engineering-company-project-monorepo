# website

Aplicacion publica de Brasaland construida con Next.js y TypeScript.

## Objetivo
Migrar y mejorar la web corporativa del Hito 1 con componentes reutilizables y estilo consistente.

## Alcance actual
- Ruta `/` con secciones completas: Hero, Menu, Locales, Nosotros y Rewards.
- Componentes reutilizables en `src/components/website`.
- Layout y estilo alineado a la identidad visual existente.

## Scripts
- `npm run dev`
- `npm run build`
- `npm run lint`
